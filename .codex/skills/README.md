# Project skills

这些技能来自 [rrezartprebreza/spring-boot-skills](https://github.com/rrezartprebreza/spring-boot-skills) 的 Spring Boot 4 目录，并按本项目的 Spring MVC、MyBatis-Plus、Redis、JWT 和 `Result<T>` 契约做了适配。

## 已引入

- `configuration-properties`
- `layered-architecture`
- `rest-api-conventions`
- `spring-data-redis`
- `transactional-patterns`
- `testing-pyramid`
- `production-observability`
- `idempotency-patterns`
- `demo-hub-conventions`：本项目新增的 Demo Hub 专属规范

## 适用边界

仓库中的 JPA、Flyway、WebFlux、Spring AI 和 MCP 技能没有直接引入，因为当前项目分别使用 MyBatis-Plus、增量 SQL、Spring MVC，且暂未使用 AI/MCP。未来更换技术栈时再单独评估。
